🎲 Play Different

Website Planning Document

Site Name

Play Different

The name "Play Different" was selected because this website will show and teach about board games that are outside the usual expectations. When people think about board games they often think about Monopoly or Uno, but there are hundreds of other modern games available. This site will help people discover those different experiences.

Optional domain availability: playdifferent.com

Site Purpose

The purpose of this website is to provide information about popular modern board games. The site will include images, descriptions, number of players, difficulty levels, and average playing time. The goal is to help beginners and hobby players discover new games and learn basic information about them.

Scenarios

  • What are some good beginner board games?
  • Which board games work best for 4 players?
  • What board games take less than one hour to play?
  • Which games are considered strategy games?
